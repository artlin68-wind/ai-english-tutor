# AI 英語家教（PWA）

一個可以裝在手機主畫面、全家每天練英文會話的網頁 App。
完全免費：語音用手機內建引擎，AI 對話用 Google Gemini 免費額度。

## 檔案結構

```
index.html              主程式（整個 App）
manifest.webmanifest    PWA 設定（可安裝、圖示）
sw.js                   Service Worker（可離線開啟介面）
icons/                  App 圖示（192 / 512 / maskable / apple-touch）
ai_english_teacher.html 舊版原型（保留參考，可刪）
tools/make_icons.py     產生圖示的腳本（改圖示時才用）
```

## 功能

- 選程度（小孩 / 初學 / 成人）→ 選老師（Ryan / Emma）→ 選情境對話
- 13 種情境：生活、旅遊、購物、書信、點餐、面試、看醫生、電話、校園、銀行、租屋、緊急求助、閱讀文章（可擴充）
  - 📖 閱讀文章內建 6 篇不同主題短文（環保/旅遊/健康/科技/動物/飲食），每次隨機一篇；填 Gemini 金鑰則每次生成全新文章
- 老師唸英文（TTS）、你可用麥克風說（STT）、發音吻合度回饋
- 單字卡（練習與應用）：對應高中 7000 官方 **Level 1-6 分級**，卡上可切級；每字 emoji圖像 + 音標 + 發音 + 詞性 + 中文 + 例句。目前共 193 字（L1:30/L2:38/L3:50/L4:25/L5:25/L6:25），持續分批擴充中
  - **單字庫可線上更新**：單字資料放在 `words.json`，App 開啟時自動讀取（讀不到就用內建、離線可用）。要加字只要編輯 `words.json` 重新上傳到你的網站，全家 App 下次開啟自動更新，不用重裝
- 🗣️ 自由聊天（AI 糾錯）：填 Gemini 金鑰後可聊任何主題，老師會用「✏️ Better:」示範正確說法
- 🌐 翻譯機：貼英文（單字到整篇文章）→ 中文，也能中→英，可朗讀（需 Gemini 金鑰）
- 👆 單字點選翻譯：對話中點老師的英文單字 → 顯示中文與音標、可發音（本地字庫優先，其餘用 AI 查）
- 🎧 語音對話（免持）：對話工具列的按鈕開/關。⚙️設定的「真免持模式」關閉＝手機內建辨識（省、Android全自動、iPhone每輪點一下）；開啟＝錄音+靜音偵測+Gemini轉文字（iPhone也全自動，需金鑰、稍慢、較耗額度）
- 🎤 發音矯正（跟讀）：聽正確發音（正常/慢速）→ 你唸 → 逐字標對錯 + 吻合度分數；紅字可點聽正確慢速發音（依程度練習句，Android Chrome 辨識最佳，iPhone Safari 較受限則改聽讀對照）
- 單字測驗（依程度出題）
- 「想不出來 / 再說一次 / 中文」三顆輔助鈕
- **每日打卡連續天數 🔥 + XP ⭐**：練習就加分，首頁顯示，鼓勵每天使用
- **免費真 AI 對話**：填入 Gemini 金鑰後，老師會即時理解並回應任何內容
- 橘白亮色系介面 + 每情境專屬氛圍背景（本地離線、無版權）
- 設定可調老師語音、說話速度（含試聽）、**介面大小（文字＋圖示一起縮放 80%–160%）**、**主題配色（橘白/藍海/森綠/蜜桃粉/溫柔紫/夜間護眼，一鍵換背景＋文字＋icon 色）**；Ryan 年輕男聲、Emma 甜美上班族女聲
- 程度（小孩/初學/成人）差異：語速、單字測驗題庫、AI 用語都不同；生活/點餐/買東西/校園 4 個情境的對話也分程度（小孩超簡短、成人較豐富），其餘情境陸續補中

## 一、先在電腦上試玩（可選）

在這個資料夾開終端機執行：

```
python -m http.server 8765
```

然後用瀏覽器開 `http://localhost:8765/`。
（用 `localhost` 才能啟用語音與安裝功能，直接雙擊 html 檔語音會受限。）

---

## 二、取得免費的 Gemini 金鑰（讓 AI 真的會對話）

1. 用電腦或手機瀏覽器開：**https://aistudio.google.com/apikey**
2. 用 Google 帳號登入 → 按 **Create API key（建立 API 金鑰）**
3. 複製那串以 `AI...` 開頭的金鑰
4. 打開 App → ⚙️ 設定 → 貼到「Gemini 免費金鑰」→ 按「載入可用模型」→ 選一個含 **flash** 的模型（免費、快）→ 儲存

> 金鑰只存在你這台裝置（localStorage），不會上傳。
> Gemini 免費額度很大方，家庭練習用量通常都在免費範圍。
> 不填金鑰也能用「內建情境腳本」練習，完全免費。

---

## 三、免費部署到網路（全家手機才能裝）

手機要能「安裝到主畫面」並使用麥克風，需要一個 **HTTPS 網址**。
最簡單的免費做法（二選一）：

### 方法 A：Netlify Drop（最快，用拖的）
1. 開 **https://app.netlify.com/drop**
2. 把**整個資料夾**（含 index.html、manifest、sw.js、icons/）拖進去
3. 幾秒後得到一個 `https://xxxx.netlify.app` 網址 → 傳給家人

### 方法 B：Cloudflare Pages（適合長期）
1. 把這個資料夾放到一個 GitHub repo
2. 到 Cloudflare Pages → Connect to Git → 選 repo → 部署
3. 得到 `https://xxxx.pages.dev` 網址

> 不用買網域、不用伺服器、不用信用卡。

---

## 四、安裝到手機主畫面

打開上面拿到的 HTTPS 網址後：

- **iPhone（Safari）**：點下方「分享」圖示 → 「加入主畫面」
- **Android（Chrome）**：右上角選單 → 「安裝應用程式 / 加到主畫面」
  （App 內也有「📲 安裝到主畫面」按鈕）

裝好後就像一般 App 一樣有圖示，全螢幕開啟。

---

## 五、注意事項

- **語音辨識（說英文）**：Android Chrome 支援最好；iPhone Safari 支援較有限，
  不支援時可直接打字，功能一樣完整。
- **老師發音音質**：iPhone 可在「設定 → 輔助使用 → 朗讀內容 → 語音」免費下載
  高品質英語語音，App 會自動採用。
- **改版更新**：改完檔案重新部署即可；`sw.js` 裡的 `CACHE` 版本號 +1 可強制更新快取。
- **加情境 / 改題目**：直接編輯 `index.html` 裡的 `SCENARIOS` 與 `QUIZ_BANK`，
  資料驅動，不用動其他程式。
